## 自动化检查 — 2026-10-08

环境：Apple Silicon、macOS 27.0.1、Xcode 27。

- 109 项单元测试通过（含参数化用例共 110 次运行），覆盖许可证打包、本地化、音频解码、蓝牙生命周期、手势、映射导入、恢复及语音故障恢复。
- 独立公开源码快照在不含本地签名配置的情况下，使用默认临时签名通过 arm64 Release 构建。
- 公共构建和开发证书签名构建均通过严格代码签名校验。
- GPL 及中英文第三方声明均已打包；测试覆盖语言选择，并确认 GPL 保持原文。
- 模拟输入恢复测试覆盖暂时及持续失败、回读校验、有限重试、重连取消、外部输入选择和停止后的状态提示。
- XCTest UI 自动化在验证机器上因 runner 初始化超时，尚未通过。

英文界面已检查动作搜索与选择、快捷键录制与取消、应用配置继承与覆盖、JSON 导入预览与导出、无效输入处理、音频设置应用与撤销、测试音完成回调、窗口导航与布局。

这些界面检查早于最新的许可证界面和音频设置，不表示所有当前界面流程均已重新测试。
