# 权限与安全边界

[English](security.md) · **简体中文**

## 必需的访问权限

| 权限 | 用途与边界 |
| --- | --- |
| 蓝牙 | 用户连接时申请。通过 BLE 接收遥控器麦克风音频，语音采集前必须确认设备型号。发现设备时可能不按服务过滤广播，但只连接候选遥控器。 |
| 辅助功能 | 通过明确的授权按钮申请。发送语音快捷键及映射的键盘、鼠标动作。“清空文字”只检查前台元素的角色，不读取文本内容。 |
| 输入监控 | 可选的按键映射需要此权限。HID 管理器按小米厂商及产品 ID 匹配，且只接受选定遥控器的报告。macOS 授予的权限比应用实际使用范围更广，并非系统强制限定到单个设备的授权。 |

按键映射默认关闭。快捷键录制只在录制窗口打开期间使用应用内部事件监听。前台应用标识用于选择映射及取消待执行手势，不保存使用历史。登录时启动只通过用户的开关启用。

应用不申请实体麦克风、摄像头、录屏、Apple Events 自动化、完全磁盘访问或管理员权限。音频引擎向虚拟输出设备写入遥控器 PCM，输入法负责采集及识别。安装外部音频驱动属于独立操作，有其自身的权限要求。

## Release 策略

Release 启用 Hardened Runtime，并关闭基础权限注入。预期的签名 entitlement 集合为空：不包含调试器附加、JIT、未签名可执行内存、关闭库验证、App Groups 或其他运行时例外。蓝牙是唯一的用途描述键。App Group 自动注册已关闭。

App Sandbox 保持关闭，因为跨应用辅助功能与其不兼容，参见 [Apple 的沙盒限制](https://developer.apple.com/documentation/security/protecting-user-data-with-app-sandbox)。空的 entitlement 集合**不代表**应用已沙盒化，也不限制普通文件或网络访问。这些边界还依赖实现审查及 macOS 隐私控制。

每次构建 Release 后运行产物检查：

```sh
python3 scripts/check-release-security.py \
  'build/Distribution/Build/Products/Release/Mi Remote Helper.app' --distribution
```

本地临时签名的 Release 省略 `--distribution`。检查会拒绝额外的 entitlement 或用途描述，并要求 arm64、有效签名和 Hardened Runtime。发行模式额外要求 Developer ID 及可信时间戳。此检查不能证明公证通过、硬件行为正确或代码不存在恶意行为。参见[发布准备](releasing.zh-CN.md)。

## 数据与系统修改

- 本应用不记录或上传音频、转写文字。输入法的数据处理属于独立范围。
- 设置、选定设备标识和映射保存在本地偏好设置。映射导入导出只访问用户选定的 JSON 文件，并校验大小及格式，不执行导入的命令或脚本。
- 系统输入锁定有明确开关。只改变选定输入，按所有权规则恢复原输入，不改变系统播放输出。
- 常规诊断消息使用私有 OSLog 字段。Debug 语音事件诊断，包括元数据日志，必须设置 `MI_REMOTE_VOICE_DIAGNOSTICS=1` 才启用；Release 不包含这些诊断。主动启用的监听器能接收会话键盘事件，但只记录指定修饰键及语音键元数据，不记录文字或音频，字段也采用私有标记。
- 应用没有特权辅助程序、Shell 命令执行、内置更新器或网络上传客户端。外部文档及安装链接在用户浏览器中打开。

重新构建不会自动撤销已有的 macOS 授权。用户可以在“系统设置 → 隐私与安全性”中检查或撤销权限。
