## 运行时行为

- 权限、音频设备列表及不可用映射状态未改变时，不发布 UI 更新。
- 每秒健康检查查询所选音频设备的存活状态和输出绑定，不枚举全部输入输出设备。
- 每包音频均累加采样数；UI 进度发布间隔至少为 80 毫秒，收音停止时发布精确最终值。
- 音频完成回调仅保留帧数，不保留解码后的采样数组。
- Debug 键盘事件观察需通过启动环境变量 `MI_REMOTE_VOICE_DIAGNOSTICS=1` 主动开启。
